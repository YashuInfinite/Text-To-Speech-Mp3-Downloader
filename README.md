## 🚀 About

**Text-to-Speech MP3 Downloader** is a browser-based tool that converts
written text into spoken audio.

Simply enter your text, select a voice/language, and choose whether you
want to:

- ▶️ Play the generated speech
- 🎧 Preview the audio
- ⬇️ Download the speech as an MP3 file

The application provides a simple dark-themed interface designed to be
easy to use on both desktop and mobile devices.
